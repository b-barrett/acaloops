# Acaloops

Website for the Acaloops 50-Mile Fat Ass Loop Trail Ultramarathon at Acalanes Ridge Open Space in Walnut Creek, California.

**Live site:** https://acaloops.run

## Event

Acaloops is a 50-mile loop trail ultra built around an approximately 8.5-mile course with 2,400 feet of climbing per lap.

Six laps = 51 miles and 14,000+ feet of climbing.

## Site

This is a simple static website hosted with GitHub Pages.

- HTML: `index.html`
- CSS: `styles.css`
- Images and route assets: `assets/`
- Elevation profile generator: `scripts/generate_elevation_profile.py`

No framework, build system, CMS, or JavaScript is required.
